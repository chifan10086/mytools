# Poloniex Futures Bot 优化说明

## 优化时间
2026-04-22

## 优化目标
针对最近亏损问题，提升策略灵活性和汇报详细度

---

## 主要改进

### 1. 增强风控系统 (risk_manager.py)

#### 新增功能
- **交易统计追踪**
  - 总交易次数、胜率、盈亏比
  - 平均盈利/亏损、最大单笔盈亏
  - 最大回撤和当前回撤监控

- **动态仓位管理**
  - 根据近期表现自动调整仓位 (0.5x - 1.5x)
  - 连续亏损时降低仓位 (连续1次→0.8x, 2次→0.6x)
  - 表现良好时增加仓位 (胜率>60%且盈亏比>1.5 → 1.3x)

- **性能分析**
  - 最近10笔交易表现摘要
  - 实时回撤监控
  - 仓位缩放建议

#### 关键指标
```python
win_rate = 胜率 (winning_trades / total_trades)
profit_factor = 盈亏比 (total_profit / total_loss)
max_drawdown = 最大回撤 (从峰值的最大跌幅)
position_scale = 仓位系数 (0.5-1.5)
```

### 2. 优化交易策略 (strategy.py)

#### 信号质量评分系统 (0-1分)
综合评估4个维度：
1. **趋势强度 (ADX)** - 0-0.3分
   - ADX ≥ 40: 0.3分 (强趋势)
   - ADX ≥ 25: 0.2分 (中等趋势)
   - ADX ≥ 20: 0.1分 (弱趋势)

2. **成交量确认** - 0-0.25分
   - 近5根K线成交量 > 20根均值×1.5: 0.25分
   - > 均值×1.2: 0.15分
   - > 均值: 0.05分

3. **价格动量** - 0-0.25分
   - 10根K线涨跌幅与方向一致
   - 动量 > 2%: 0.25分
   - 动量 > 1%: 0.15分

4. **波动率适中** - 0-0.2分
   - ATR占价格 0.5%-3%: 0.2分 (最佳)
   - ATR占价格 0.3%-4%: 0.1分

**过滤规则**: 信号质量 < 0.3 时不开仓

#### 趋势过滤系统
防止逆势交易和假突破：

1. **长期趋势检查 (EMA50)**
   - 做多信号但价格 < EMA50×0.98 → 拒绝
   - 做空信号但价格 > EMA50×1.02 → 拒绝

2. **假突破检测**
   - 突破近期高点但立即回落 → 拒绝做多
   - 跌破近期低点但立即反弹 → 拒绝做空

## 使用建议

### 1. 监控关键指标
- **胜率**: 目标 > 50%
- **盈亏比**: 目标 > 1.2
- **最大回撤**: 警戒线 < 15%
- **信号质量**: 平均 > 0.5

### 2. 策略调整
如果持续亏损：
1. 检查市场状态是否适合当前策略
2. 考虑切换到 `auto` 策略（自动适应市场）
3. 提高信号质量阈值（修改代码中的 0.3）
4. 降低杠杆倍数

### 3. 风控参数
建议配置：
```python
MAX_CONSECUTIVE_LOSSES = 3  # 连续亏损3次停机
DAILY_LOSS_RATIO = 0.05     # 单日亏损5%停机
STOP_LOSS_RATIO = 0.025     # 止损2.5%
TAKE_PROFIT_RATIO = 0.05    # 止盈5%
```

## 技术细节

### 信号质量计算
```python
quality = ADX评分(0-0.3) + 成交量评分(0-0.25) + 
          动量评分(0-0.25) + 波动率评分(0-0.2)
```

### 仓位缩放逻辑
```python
if 连续亏损 >= 2: scale = 0.6
elif 连续亏损 >= 1: scale = 0.8
elif 胜率 > 0.6 and 盈亏比 > 1.5: scale = 1.3
elif 胜率 > 0.5 and 盈亏比 > 1.2: scale = 1.1
elif 胜率 < 0.4 or 盈亏比 < 0.8: scale = 0.7
else: scale = 1.0
```

### 趋势过滤条件
```python
# 做多过滤
if direction == 1 and price < EMA50 * 0.98:
    reject("逆势做多")

# 做空过滤  
if direction == -1 and price > EMA50 * 1.02:
    reject("逆势做空")
```
